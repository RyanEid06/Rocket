## Removal gate

The old `src.rocket_raylib` and `src.rocket_assets` files remain compatibility code while the showcase's 11 tests, legacy package checks, tooling, and historical documentation still import or name them. Remove them only after those supported consumers have been migrated and rerun. New games import the supported modules above.
