# Rocket 3 Foundation

This package contains deterministic internal Rocket 3.0 foundation kernels on
the accepted Rocket 2.1 baseline. It is intentionally not an SDK module, public
API, or release artifact until the named Rocket 3.0 public-integration packets.

WP01 supplies geometry and pure hit-testing kernels; WP02 adds deterministic
color operations; and WP03 adds layout and VirtualCanvas mathematics. The
package remains a focused test target while later packets add the remaining
foundation behavior.
