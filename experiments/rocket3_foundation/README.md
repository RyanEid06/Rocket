# Rocket 3 Foundation

This package contains deterministic internal Rocket 3.0 foundation kernels on
the accepted Rocket 2.1 baseline. Wave B has now promoted the corresponding
public graphics/UI surfaces under `stdlib/rocket`; this experiment remains an
internal traceability and focused-test package, not an SDK module or release
artifact. The current public index is `docs/ROCKET_3_0_SYNTAX_DICTIONARY.md`.

WP01 supplies geometry and pure hit-testing kernels; WP02 adds deterministic
color operations; and WP03 adds layout and VirtualCanvas mathematics. The
package remains a focused test target while Wave C adds themes, controls,
containers, and bounded-state integration.
